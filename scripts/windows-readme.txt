LipLock для Windows
===================

1. Распакуй архив в любую папку (например, C:\Programs\LipLock).
2. Запусти LipLock.exe — откроется окно с логом и браузер с интерфейсом.
   Если браузер не открылся, зайди на http://127.0.0.1:47650
3. Пока работаешь, не закрывай чёрное окно. Закрыл окно — LipLock остановился.

Файлы выбираются с любого диска прямо в интерфейсе.
Папка-автомат:  Видео\LipLock\input   (внутри: Фильм\main и Фильм\donors)
Готовое:        Видео\LipLock\output
Настройки:      %APPDATA%\LipLock

ffmpeg и mkvmerge уже лежат в папке bin — ставить ничего не нужно.
Интерфейс доступен только с этого компьютера.

Windows SmartScreen может предупредить, что программа неизвестна (у неё нет
платной подписи): «Подробнее» → «Выполнить в любом случае».

Как пользоваться, рецепты правил и разбор проверки — в README:
https://github.com/MrJosu/liplock#быстрый-старт

LipLock for Windows
===================

1. Unzip anywhere, run LipLock.exe — a log window and the browser open.
   If the browser does not open, go to http://127.0.0.1:47650
2. Keep the black window open while you work; closing it stops LipLock.

Watch folder: Videos\LipLock\input, output: Videos\LipLock\output,
settings: %APPDATA%\LipLock. ffmpeg and mkvmerge are bundled in bin.
Guide, rule recipes and how to read the check:
https://github.com/MrJosu/liplock/blob/main/README.en.md#quick-start
